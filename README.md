# Electricity Consumption Analysis

This project analyzes daily electricity consumption using Python and Data Science techniques.

## Project Overview

The project uses a simple dataset containing electricity consumption for each day of the week. Python is used to calculate important statistics and visualize the consumption pattern.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab

## Analysis Performed

- Total weekly electricity consumption
- Average daily consumption
- Highest electricity consumption
- Lowest electricity consumption
- Daily electricity consumption visualization

## Key Findings

- Highest consumption: Saturday — 13.5 units
- Lowest consumption: Wednesday — 7.8 units
- Average daily consumption: approximately 10.37 units

## Conclusion

The analysis shows that electricity consumption varies throughout the week. This type of analysis can help understand electricity usage patterns and identify high-consumption days.
